Real (non-synthesized) builtin sounds in this folder are from Kenney.nl
asset packs, released under CC0 (public domain, no attribution required):

- fx/laser-retro.mp3 — from "Sci-fi Sounds" (kenney.nl/assets/sci-fi-sounds)
- fx/impact-metal.mp3 — from "Impact Sounds" (kenney.nl/assets/impact-sounds)

Every other builtin sound (drums, bass, melody, vocal) is still synthesized
in-browser via lib/builtinSounds.ts — see that file for how to swap more
categories to real audio files.
